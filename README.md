# Nyaya Companion

hey , this is how my current ui/ux looks like for my project
project: Nyaya is an AI chatbot built to make constitutional rights and legal aid accessible to everyday Indians, in their own language. It answers questions on the Constitution, arrest rights, RTI filing, and consumer grievances by grounding every response in real legal text with exact Article citations, rather than relying on the model's own memory. The entire system runs on a local LLM (Qwen 3 14B via Ollama), so no query — including sensitive ones — ever leaves the user's device. It supports English, Hindi, and Tamil, and goes beyond information by helping users draft complaints and locate their nearest legal aid authority. Built for a 2-day hackathon, it targets the real gap between knowing a right exists and knowing how to act on it.
